# 🚀 NOVADECK — Premium SaaS Landing Template

A dark, high-conversion landing page built with Next.js, TypeScript, Tailwind CSS v4, and Lucide Icons. Designed specifically for modern SaaS, AI startups, and digital product showcases.

🌐 Live Preview: https://nova-deck-omega.vercel.app/

---

## ⚡ Key Features

* Responsive Navbar: Optimized navigation featuring a smooth, animated mobile menu toggle.
* Hero Section: High-impact modern design featuring a pure CSS antigravity core (no heavy external images required).
* Features Grid: A sleek grid layout optimized to showcase core product functionalities.
* Showcase Section: A premium “What you get” visual breakdown of your product or service.
* Pricing & FAQ: Fully styled pricing comparison tables alongside an expandable interactive FAQ accordion.
* Footer Layout: Comprehensive footer structure with organized, categorized navigation links.

---

## 🛠️ Tech Stack & Architecture

* Framework: Next.js (Modern App Router)
* Library: React 19
* Language: TypeScript
* Styling: Tailwind CSS v4
* Icons: lucide-react

### Project Directory Structure

src/
├── app/          # Layouts, main page router, and global CSS styles
├── components/   # Modular components (Navbar, Hero, Features, Showcase, Pricing, FAQ, Footer)
└── lib/          # Configuration (Edit site metadata, branding, and contact details in site.ts)

---

## 💻 Quick Start & Installation

Follow these steps to set up the project locally:

1. Install Dependencies:
   npm install

2. Run the Development Server:
   npm run dev
   (Open http://localhost:3000 in your browser to view the project)

3. Production Build:
   npm run build
   npm start
